# Yandex Disk UI + API Automation

Автотесты для сервиса Яндекс Диск, в которых UI- и API-шаги объединены в один сквозной сценарий: файлы создаются и изменяются через REST API, а результат проверяется в веб-интерфейсе, и наоборот.

## Стек

* Java 25, Maven
* TestNG (в том числе SoftAssert)
* Aquality Selenium (обёртка над Selenium WebDriver)
* RestAssured
* Jackson, Lombok
* JavaFaker

## Что проверяют тесты

Сквозной сценарий `DiskTest` проверяет полный жизненный цикл файла на Диске: загрузку, переименование, перезапись, удаление в корзину, восстановление и окончательное удаление. Действия выполняются через REST API, а их результат проверяется в веб-интерфейсе без обновления страницы. Дополнительно проверяется содержимое файлов во встроенных просмотрщиках.

## Архитектура проекта

1. `main/java/api` — классы для взаимодействия с HTTP API Яндекс Диска.
   * `BaseApi` — абстрактный базовый класс для отправки запросов. Скрывает работу с библиотекой RestAssured и сериализацию/десериализацию JSON.
   * `DiskApi` — клиент для запросов к эндпоинтам Диска (создание, перемещение, удаление, работа с корзиной).
   * `Endpoints` — константы с путями API.
   * `ApiResponse<T>` — обобщённая обёртка для ответов.
2. `main/java/constants` — строковые шаблоны и константы:
   * `ApiConstants` — шаблоны для работы с API (например, префикс токена `OAuth %s`).
   * `AuthConstants` — константы для UI-авторизации (название и домен сессионной cookie).
3. `main/java/enums` — перечисления для параметров и заголовков:
   * `HttpHeader` — названия HTTP-заголовков (например, `Authorization`).
   * `QueryParam` — ключи query-параметров API (например, `path`, `overwrite`, `from`, `limit`, `sort`).
4. `main/java/models` — POJO-классы для десериализации JSON-ответов API:
   * `LinkResponse` — модель ссылки (например, для загрузки файла).
   * `TrashResourceList`, `TrashEmbedded`, `TrashItem` — модели для поиска удалённых объектов в корзине.
5. `main/java/pages` — классы Page Object для работы с веб-интерфейсом: `MainPage`, `DiskPage`, `TextEditorPage`, `ImageViewerPage`.
6. `main/java/utils` — вспомогательные классы, разделённые по принципу единственной ответственности:
   * `TestDataUtils` — генерация случайных слов и предложений с помощью JavaFaker.
   * `FileUtils` — работа с файловой системой (создание временных `.txt` файлов, копирование тестового изображения в `target/`).
   * `ConfigManager` — чтение настроек из JSON. Токен и `Session_id` маскируются в логах.
7. `test/java/tests/base` — базовый класс `BaseTest`, управляющий жизненным циклом браузера (запуск, разворачивание окна, закрытие).
8. `test/java/tests` — тестовые сценарии.

## Конфигурация и данные

* `src/test/resources/settings.json` — настройки фреймворка: параметры Aquality Selenium (браузер, таймауты), базовые URL для UI и API, авторизационные данные (`sessionId` для браузера и OAuth `token` для API).
* `src/test/resources/img.jpg` — изображение, которое тесты загружают на Диск.

## Подготовка к запуску

Тестам нужен отдельный тестовый аккаунт Яндекса. Сессионная cookie и токен имеют ограниченный срок жизни, поэтому перед запуском их нужно получить заново:

1. Войдите в тестовый аккаунт на disk.yandex.ru в браузере.
2. Откройте инструменты разработчика (F12 → Application → Cookies) и скопируйте значение cookie `Session_id`.
3. Получите OAuth-токен с доступом к Яндекс Диску через сервис oauth.yandex.ru.
4. Вставьте значения в `src/test/resources/settings.json`:

```json
{
  "sessionId": "СЮДА_ВСТАВИТЬ_SESSION_ID",
  "credentials": {
    "token": "СЮДА_ВСТАВИТЬ_OAUTH_TOKEN"
  }
}
```

Не коммитьте файл с реальными значениями в репозиторий.

## Запуск тестов

Требуется установленный JDK 25 и Maven.

**Через IDE (IntelliJ IDEA)**

1. Откройте папку проекта, в которой лежит `pom.xml`.
2. Дождитесь импорта Maven-зависимостей и индексации.
3. Откройте класс `src/test/java/tests/DiskTest` и нажмите кнопку Run рядом с названием класса или метода.

**Через терминал**

Перейдите в папку проекта, в которой лежит `pom.xml`, и выполните:

```bash
mvn clean test
```

Если при первом запуске скачивание зависимостей зависло, прервите выполнение и запустите с принудительным обновлением:

```bash
mvn clean test -U
```
